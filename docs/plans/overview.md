# Overview

Minimal Express + TypeScript + TypeORM/PostgreSQL API boilerplate: decorator controllers, static services wired by `@Initializer()`, OpenAPI request validation, generated error codes, stateless JWT auth (local register/login), pino logging.

Current work: [spec-boilerplate-upgrade.md](spec-boilerplate-upgrade.md) — bug fixes, cleanup, dependency upgrade (Node 24, Express 5, ESLint 9), type-safe error codes, auth/CRUD test coverage.
